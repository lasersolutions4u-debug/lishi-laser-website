Product Architecture

Two decisions. One coherent gas path.

A PSA system is an optional upstream nitrogen source. If mixed-gas cutting is required, the integrated cabinet and MSPV2_4000 perform the same core function—choose one according to installation form and integration responsibility.

Review the existing source first. Add PSA only when it is the appropriate upstream supply for the project.

Selection rule

Pure-nitrogen cutting bypasses mixed-gas control. If mixed gas is selected, choose one controller by gas conditions, space, interfaces and engineering responsibility.

FAQ

Frequently Asked Questions

Which products are included in the GasMixTech assist-gas system?

The current product family covers an optional PSA nitrogen source plus two alternative N₂/O₂ mixed-gas controllers: the integrated cabinet and MSPV2_4000 compact valve.

Do I need a PSA nitrogen generator?

Not necessarily. PSA is an optional upstream nitrogen source. Retain an existing nitrogen supply when it already meets the confirmed purity, pressure, flow, and operating requirements.

Should the integrated cabinet and MSPV2_4000 be installed together?

No. They perform the same core mixed-gas control function in different product forms. Choose one according to installation space, interfaces, and integration responsibility.

Does pure-nitrogen cutting require a mixed-gas controller?

No. Pure-nitrogen cutting bypasses the mixed-gas controller. A controller is selected only when the reviewed process requires an N₂/O₂ mixture.

How do you confirm compatibility with my laser?

Compatibility cannot be confirmed by brand or power alone. We review assist-gas demand, gas sources, pressure, flow, material range, machine interface, piping, and installation conditions together.

Where can I review operating impact and cutting parameters?

Use the dedicated ROI review and parameter pages. Their values are reference inputs and must be checked against your local operating data and complete process conditions.

Which product does the current cutting evidence belong to?

The current published parameter tables and recorded cutting videos remain attached to the integrated cabinet platform. They must not be treated as universal evidence for the compact valve.

What information is required before quotation?

Send the laser brand and power, materials and thicknesses, current gas method, nitrogen and oxygen sources, available pressure and flow, installation space, and production objective. For a qualified One-to-Three multi-machine review, also provide simultaneous demand, pipe routing, and each machine interface.
